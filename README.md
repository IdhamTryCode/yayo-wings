# Yayo Wings - Modern Restaurant Website

A fast, responsive, and visually stunning website for **Yayo Wings**, featuring a modern aesthetic with glassmorphism and smooth animations. Built with a mobile-first approach to ensure the best experience for customers on all devices.

## 🚀 Tehnologies

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Responsiveness**: Mobile-first design

## ✨ Key Features

- **Modern UI**: Clean design with glassmorphism effects and tailored color palettes.
- **Interactive Menu**: Organized categories (Chicken Wings, Drinks, Snacks, Add-ons) with real product photos.
- **Ordering System**: Integrated order platform selection (WhatsApp, GoFood, GrabFood, ShopeeFood, Maxim).
- **SEO Optimized**: Meta tags and Schema.org JSON-LD for local restaurant visibility.
- **Smooth UX**: Loading screens, parallax effects, and intuitive navigation.

## 💻 Getting Started

### Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

### Production Build
1. Create optimized production bundle:
   ```bash
   npm run build
   ```
2. Preview production build:
   ```bash
   npm run preview
   ```

## 📂 Project Structure

- `src/components/sections`: Page sections (Hero, About, Menu, etc.)
- `src/components/ui`: Reusable UI components
- `src/components/animations`: Framer Motion wrappers
- `src/data`: Menu items and contact information
- `src/hooks`: Custom React hooks for effects and interactions
- `public/images`: Optimized brand assets (Store logo, Product photos)
