# Yayo Wings - Korean Wings Terenak di Demak

Website modern dan responsif untuk **Yayo Wings**, restoran Korean Wings terenak di Demak. Nikmati ayam goreng Korea dengan saus spesial, harga mulai Rp 13.000. Pesan online via GoFood, GrabFood, ShopeeFood sekarang!

## 🍗 Tentang Yayo Wings

**Yayo Wings** adalah restoran spesialis Korean Wings yang berlokasi di Demak, Jawa Tengah. Kami menyajikan ayam goreng Korea dengan bumbu autentik dan saus spesial yang bikin nagih. Dengan harga terjangkau mulai Rp 13.000, Yayo Wings menjadi pilihan terbaik untuk pecinta kuliner Korea di Demak.

### Menu Favorit Kami:
- **Korean Wings** - Ayam goreng Korea dengan saus spesial
- **Paket Hemat** - Paket makan terjangkau untuk keluarga
- **Minuman Segar** - Es Teh Jumbo dan minuman lainnya
- **Snack** - Cireng Mercon, Gyoza, dan snack lainnya

## 🚀 Teknologi

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Responsiveness**: Mobile-first design
- **SEO Optimized**: Meta tags, Schema.org JSON-LD, robots.txt, sitemap.xml

## ✨ Fitur Utama

- **Modern UI**: Desain bersih dengan efek glassmorphism dan palet warna yang menarik
- **Menu Interaktif**: Kategori terorganisir (Chicken Wings, Minuman, Snack, Add-on) dengan foto produk asli
- **Sistem Pemesanan**: Integrasi platform pemesanan (WhatsApp, GoFood, GrabFood, ShopeeFood, Maxim)
- **SEO Optimized**: Meta tags dan Schema.org JSON-LD untuk visibilitas restoran lokal
- **UX yang Halus**: Loading screen, efek parallax, dan navigasi intuitif
- **Mobile Friendly**: Desain responsif yang optimal untuk semua perangkat

## 💻 Memulai

### Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

### Production Build
1. Create optimized production bundle:
   ```bash
   npm run build
   ```
2. Preview production build:
   ```bash
   npm run preview
   ```

## 📂 Struktur Proyek

- `src/components/sections`: Bagian halaman (Hero, About, Menu, dll)
- `src/components/ui`: Komponen UI yang dapat digunakan kembali
- `src/components/animations`: Wrapper Framer Motion
- `src/components/seo`: Komponen SEO untuk meta tags dinamis
- `src/data`: Item menu dan informasi kontak
- `src/hooks`: Custom React hooks untuk efek dan interaksi
- `public/images`: Aset brand yang dioptimalkan (Logo restoran, Foto produk)
- `public/robots.txt`: File untuk mengontrol crawler search engine
- `public/sitemap.xml`: Sitemap untuk search engines

## 🔍 SEO Optimization

Website ini telah dioptimalkan untuk SEO dengan:

1. **Meta Tags Lengkap**: Title, description, keywords, Open Graph, Twitter Cards
2. **Structured Data (JSON-LD)**: Schema.org untuk Restaurant, FAQ, LocalBusiness
3. **Robots.txt**: Mengatur crawler search engine
4. **Sitemap.xml**: Sitemap untuk memudahkan indexing
5. **Semantic HTML**: Struktur HTML yang semantik
6. **Image Alt Tags**: Alt text yang deskriptif untuk semua gambar
7. **Mobile-First Design**: Responsif untuk semua perangkat
8. **Fast Loading**: Optimasi performa dengan Vite
